## 機能一覧

### ユーザー・認証機能
- ユーザー登録
- ログイン
- ログアウト
- ユーザー情報の管理

### 製品管理機能
- 製品一覧の表示
- 製品の登録
- 製品の編集
- 製品の削除
- 製品ごとの必要部品・必要数量の登録

### 部品管理機能
- 部品一覧の表示
- 部品の登録
- 部品の編集
- 部品の削除
- 部品単価の管理

### 製品注文管理機能
- 製品注文の登録
- 製品注文一覧の表示
- 製品注文数から必要部品数を自動計算

### 在庫管理機能
- 部品ごとの理論在庫数の表示
- 入庫による在庫数の更新
- 出庫による在庫数の更新
- 必要部品数と現在庫の比較
- 不足部品数の自動計算

### 発注管理機能
- 不足部品から発注数量を自動計算
- 部品単価と発注数量から発注金額を自動計算
- 複数部品の発注合計金額を自動計算
- 発注候補一覧の表示
- 発注データの登録
- 発注履歴の表示
- 発注詳細の表示

### 棚卸し機能
- 実在庫数の入力
- 理論在庫数と実在庫数の比較
- 在庫差異の自動計算
- 棚卸し結果の登録
- 棚卸し後の理論在庫数の補正

### 共通機能
- 入力値のバリデーション
- 認証・アクセス制御
- エラーハンドリング
